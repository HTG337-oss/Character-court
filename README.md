# Character Court
A website where fictional characters - from books, anime, manga, and beyond - get put on trial for controversial or morally ambigous actions. 
Each case presents the charges, the evidence, arguments for and against, and acknowledges the "gray zone" where law doesn't cleanly apply. Built around themes of justice vs. good, and complicity in flawed systems.
 ## Tech
 HTML, CSS, AND JavaScript - built from scratch, hand-typed, as a personal passion project blending law, literature, and coding.
 ## Status
 Work in progress -  actively being built.
